This is the source branch README. SCOPE-specific project knowledge is contained

## README publication

On `source`, this file describes the project and its source tree. Publication
automation replaces it on generated `canary`, `beta`, and `stable` branches with
the localized channel-facing README rendered from `content/repo/`.

Do not place release-facing README content directly in this file. Update the
localized catalogs and template under `content/repo/` instead.
