# Project Documentation

This is the source branch README. KERO-specific project knowledge is contained
under `.kero/`; ordinary `docs/` is not part of KERO's integration contract.

## README publication

On `source`, this file describes the project and its source tree. Publication
automation replaces it on generated `canary`, `beta`, and `stable` branches with
the localized channel-facing README rendered from `publication/repository/`.

Do not place release-facing README content directly in this file. Update the
localized metadata and template under `publication/repository/` instead.
