# SCOPE Checklists

This directory records project work state. Checklists do not define behavior,
policy, ownership, or implementation truth; canonical contracts remain in the
registered `.scope/knowledge/` environment.

The proposed implementation hub is
[`initial-release-plan.md`](initial-release-plan.md). It names the approved
work order, expected file tree, implementation deliverables, and evidence for
the first release. The active public-release gate is
[`release-v1.md`](release-v1.md). Work proceeds from scope freeze and
implementation evidence through hardening and release rehearsal. Public
documentation and repository setup are intentionally the final stage so they
describe only behavior proven for version 1.
