# macOS ARM64

macOS ARM64 is the current macOS release architecture. It uses Apple Clang/Xcode
for the selected Qt visual-client build and produces a DMG containing the
common KERO service/client roles and portable core.

The target requires a locally owned macOS ARM64 host.

## Reconsider when

Add additional macOS architecture leaves only when KERO actually supports and
packages those targets; do not create placeholder architecture nodes merely for
symmetry.
