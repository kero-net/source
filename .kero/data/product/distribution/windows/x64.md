# Windows x64

## Toolchain

The current target uses the LLVM/MinGW Qt kit. Its compiler, resource compiler,
and runtime directory are supplied from that same x64 toolchain through
`KERO_CXX_COMPILER`, `KERO_WINDRES`, and `KERO_RUNTIME_DIR`.

Do not build this target from an MSVC developer environment as though the ARM64
and x64 Qt kits shared one compiler/runtime contract.

## Why

The selected x64 Qt kit is a different ABI/toolchain family from the ARM64 Qt
kit. Keeping compiler and runtime inputs together prevents accidental cross-kit
linking or deployment.

The target requires a local Windows x64 host or configured local Windows x64 VM.

## Reconsider when

Revisit these variables and compiler assumptions if the selected x64 Qt kit
changes.
