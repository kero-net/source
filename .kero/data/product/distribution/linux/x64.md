# Linux x64

Linux x64 is the current Linux release architecture. It uses the native
GCC/Clang toolchain required by the selected Qt/build environment and produces
an AppImage.

Development packaging may complete without a configured GPG key, but
publication is blocked until the detached signature is present and the
SHA-256 checksum verifies.

The target requires a local Linux x64 host, WSL/Docker-compatible Linux environment,
or configured local Linux VM.
