# Stage 11 — Application and CLI refinement

**Planned.** Improve the application and CLI using evidence from functional
testing.

This stage adjusts presentation, navigation, command ergonomics, progress,
diagnostics, and recovery guidance. It does not redefine product semantics or
hide functional failures; changes must preserve the service contract proven in
stage 10.

## Completion evidence

- Common workflows are understandable without implementation knowledge.
- CLI help, output, and errors are actionable and consistent.
- The Qt client clearly communicates current state, progress, and recovery.

Stage 12 then proves the refined product on supported native platforms.
