# Stage 10 — Functional testing

**Planned.** Test the completed service, CLI, and application workflows as a
product.

The stage validates behavior before interface polish or release work. It covers
service lifecycle, repository and mount operations, knowledge input,
processing, trust, persistence, error recovery, and the agreement between CLI
and Qt client results.

## Completion evidence

- Automated and documented manual flows cover each supported user operation.
- Failure, restart, and recovery paths have expected results and diagnostics.
- CLI and app observations agree for the same local environment.

Stage 11 uses this evidence to refine the application and CLI experience.
