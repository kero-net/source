# Source repository

`kero-net/src` is the authoritative implementation repository. Its canonical
branch is `source`.

It owns the Rust/KERO implementation, source documentation, authored shared
assets, release records and capture configuration, localization data,
publication templates, source-side GitHub automation, and this `.kero/`
knowledge environment.

Generated public channel content is produced from this repository but is not
hand-authored here as a release branch.
